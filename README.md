# Bunifulab

Receipt-style link tree / portfolio for Mark Mgharo (Bunifulab), Mombasa, Kenya.

Single static file: `index.html`. No build step, no dependencies (fonts load from Google Fonts).

## Deploy
- **Vercel:** import this repo, framework preset "Other", no build command, output directory is the repo root.
- **GitHub Pages:** Settings > Pages > deploy from branch `main`, `/ (root)`.

## Edit
Each project is an `<a class="item">` block. Copy one, change the link, name, tag (LIVE / DEMO / SRC / OSS) and description. Bump the `--i` value on new lines so the print animation stays in order.
